# Authentication Screen Prototypes

React screens exploring login, signup, and password-recovery navigation.

## Routes

[App.js](src/App.js) maps `/login`, `/signup`, `/signuptwo`, `/forgot`, and `/forgottwo` with React Router. Unmatched paths redirect to `/login`.

## Structure

Screen components and their styles are in [src](src); the HTML entry point is in [public](public).

## Running this snapshot

The repository has no package manifest. Restore its React and React Router build configuration before attempting `npm install` or launching the app.

## Scope

This is a collection of interface prototypes. The presence of login and recovery screens does not establish a working authentication or password-reset service.
